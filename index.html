How rankings work

Enemy heroes and recognized items contribute threat scores. Each counter is ranked by relevant protections and synergy. This is a learning prototype, not a measured win-rate model.

Game-safety boundary

Process-name checks only, plus opt-in reading of a user-selected JSONL event feed. No memory reading, game injection, overlay, input automation, or network telemetry collector. Live item tracking still requires an authorized external data source.
